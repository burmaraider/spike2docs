Stern SPIKE2, as its games see it

SPIKE2 is the electronics platform of Stern pinball machines from 2016 on: one CPU board running Linux, and a chain of small microcontroller boards that read the switches and drive the coils, motors and lamps. These pages describe that hardware from the software's side: what the game program opens, what it sends, and what it expects back.

They are the working notes of a static recompilation project, which turns the game on an SD card into a native program for a PC and has to stand in for every piece of hardware the game talks to. What is written here is what that took to find out.

Read this first: nothing here was captured from, or run on, real hardware. Everything is read from the software on game cards and from what that software does when it runs against a simulator. Each statement carries one of the tags below.

Pages

CPU board

The Linux computer in the backbox: the device nodes the game opens, the chips on its I2C bus, the cabinet switches it reads itself, its displays and its two sound codecs.

Node boards

The node bus and the boards on it: frames, every command and reply byte by byte, switches, coils, steppers, lamps, firmware and the boot loader. With a message decoder.

LCD node

The node board that drives small picture screens on the playfield, as Batman 66 uses it: frames kept in the board's own flash and played by number.

SD card

What is on a game's card: partitions, the system, the game folder and its files, and how the system starts the game.

All four are current releases and were built with the same compiler and system libraries. An address belongs to the one build it is given for: the same code sits somewhere else in every other build.

The recompilation itself, and the tool that builds a game from a card image, are in the repository these pages belong to. No game code or data is part of it.
